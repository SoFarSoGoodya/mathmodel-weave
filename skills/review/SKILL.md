# Review

Start in a fresh context with only fixed candidate/comparison/experiment material needed for the review. Do not inherit author chat history or an asserted recommendation.

Review mathematical validity separately from fair programmatic comparison. Mathematical review checks assumptions, derivations, units, identifiability, constraint handling, uncertainty, and conclusion scope. Programmatic comparison checks fixed data/splits, metric units and recomputation, baseline relevance, budget equality, leakage, coverage, failures, and denominators.

State evidence and unresolved issues precisely. A finite experiment is not an asymptotic proof; a successful process is not scientific validity; parent validity does not transfer to a fusion. Recommend a new bounded experiment or a human decision only when it could alter the conclusion.
