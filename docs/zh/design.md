# 设计

确定性控制平面负责 case 状态、任务身份、权限、人工决定、证据引用、运行清单和不可变论文包。受管 worker 可以提出路线和产物，但不能创建人工决定，也不能静默替换已选对象。

数据流为：导入 -> 校正后的题目与证据 -> 候选路线和比较契约 -> 运行尝试 -> 观测与检查 -> 选定结果 -> 论文和 AI 使用详情 -> 精确包批准与导出。

六个模块分别是 runtime（进程监督）、control（人工门控）、evidence（导入与冻结）、exploration（候选路线与比较）、execution（声明式运行）和 publication（图、TeX、检查与打包）。详见 `docs/modules/`。
